# 🍄 Mini Mario — Pixel Edition

> 一个纯 HTML/CSS/JS 打造的像素风迷你马力欧游戏，致敬经典红白机。

🎮 **立即游玩 →** https://trumpt123-crypto.github.io/super-mario-game

---

## 🎯 游戏特色

- 🕹️ **经典马力欧玩法** — 跑酷、跳跃、吃金币、踩蘑菇
- 🎨 **像素艺术风格** — 原汁原味的 8-bit 视觉，搭配复古 HUD 界面
- 📱 **多端适配** — 支持桌面键盘操作 & 手机触摸控制
- ⚡ **零依赖** — 纯前端实现，无需安装任何东西，浏览器打开即玩

## 🎮 操作方式

| 平台 | 操作 |
|------|------|
| 🖥️ 桌面 | 方向键 ← → 移动，空格 / ↑ 跳跃 |
| 📱 手机 | 屏幕虚拟按键，触摸操控 |

## 🚀 技术栈

- HTML5 Canvas 游戏渲染
- CSS3 像素风视觉设计
- 原生 JavaScript 游戏逻辑

## 📦 本地运行

直接双击 `index.html` 用浏览器打开即可。
